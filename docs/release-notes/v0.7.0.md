## Miya Island v0.7.0 ✨

这一版主要是外观和手感的大改版，同时加了几个实用的小功能。

### 外观
- 全新的 Liquid Glass 玻璃外壳，展开和收起时平滑变形
- 五种玻璃风格：Milk / Rose / Lavender / Midnight / Clear Glass，可以自定义颜色和浓度
- 背景模糊，可调模糊强度
- 三种收起样式：普通条 / 小胶囊 / 小圆
- 页签改成纯图标，选中时是实心图标
- 新的应用图标和默认头像

### 新功能
- 任务与提醒：一次性、每天、每周；提醒卡可以完成、延后、忽略
- 头像与开机问候（可以自定义称呼和问候语），安静模式
- 呼吸灯颜色可选，头像光环和角标跟着变色
- 截图页（调用 Windows 截图工具）
- 开机自启（默认关闭）
- 截图和录屏时隐藏小岛（开关）

### 悬浮歌词
- 重新设计，完全独立于小岛
- 拖到屏幕中线附近会自动吸附，并显示参考线；菜单里可以一键水平居中
- 在线歌词大幅增加：自动清理歌名里的版本后缀，并增加网易云作为后备来源
- 没找到歌词时，点一下歌词框就能重新查找

### 修复
- 展开后很难拖动
- 输入文字时小岛会自己收起
- 启动问候被提醒挡住后就不再出现

### 使用
下载下面的 `MiyaIsland.exe`，先退出旧版，再双击打开。设置和任务会自动沿用。
如果 Windows 提示“已保护你的电脑”，点“更多信息” → “仍要运行”。
