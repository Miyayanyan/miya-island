## Miya Island v0.7.1

小修复版本。

### 修复
- 有些情况下识别不到正在播放的音乐（比如浏览器里有暂停的视频时，小岛会跟着浏览器）。现在小岛会自动选择**正在播放**的那个软件，播放 / 暂停 / 下一首也会控制它。

### 如果还是识别不到
小岛是通过 Windows 的「系统媒体控制」获取歌曲信息的。放歌时按一下键盘的**音量键**，看看弹出的音量框里有没有歌名和封面：
- **有**：请告诉我们，这是小岛的问题；
- **没有**：说明这个音乐软件没有把歌曲信息告诉 Windows，更新音乐软件到最新版通常就能解决。

### 使用
下载下面的 `MiyaIsland.exe`，先退出旧版，再双击打开。设置和任务会自动沿用。
