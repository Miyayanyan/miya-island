> 用户确认：**Claude 的视觉方案页就是最终要落地的效果**。现在实物和方案页还有明显差距，这一部分专门补齐。
> **顺序：B → D → C**（D 比 C 优先）。

## 怎么对照

- 方案页已经放进仓库：`docs/v0.7/design/miya-v07-design.html`。用浏览器直接打开，不需要联网，字体加载失败也不影响。
- 页面顶部的「实时预览」可以设置：玻璃 preset 选 **Midnight**、渲染选 **仿玻璃**、背景选 **浅色壁纸**、小岛状态切 **收起 / 展开 / Compact**，点 tab 可以看各个面板。
- **对照方法**：小岛缩放设为 100%，把实物截图和方案页截图并排比较。每一项完成后，在报告里放一组「方案 / 实物」对比图：`docs/v0.7/reports/images/4D-*.png`。
- 方案页里的 CSS 数值（尺寸、圆角、颜色、动画时长）就是规格，可以直接照抄。

**唯一的例外**：按钮保持**圆角矩形**（`Radius.Button = 8`，用户的明确要求），不照方案页的胶囊形。播放键是圆形透镜。开关按方案页（胶囊 + 圆球），Claude 已经改好了（提交 `cbc9643`）。

## D1 · 顶部页签：带文字 + 滑动透镜
