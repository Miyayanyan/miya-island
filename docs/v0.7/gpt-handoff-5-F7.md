# 任务包 #5 · F7：背景模糊（实时截取 + 模糊，用户确认）

> 用户想要方案页 / 效果图那种磨砂玻璃：后面是什么就糊开什么。系统 Acrylic 已经证明不适合会变形的胶囊（就是 F1 拿掉的那个实验功能），所以改成**小岛自己截取身后画面再模糊**。
> 用户已经接受这个代价：**开启后，截图和录屏里小岛会隐身**。所以这个功能必须做成可以随时开关的选项。
> 并入任务包 #5，单独一个提交。

## 设置与入口
- 新设置 `BackgroundBlur`（bool，默认 false）。
- 设置窗口「外观」页加开关「**背景模糊**」，说明文字：“开启后截图和录屏时小岛会隐身，需要截图时可以临时关闭”。
- 托盘菜单加一项可以勾选的「背景模糊」，方便临时开关。
- 系统不支持时（见下面的隐身部分），开关置灰，并提示“需要 Windows 10 2004 或更新版本”。

## 实现
### 1. 隐身
- 开启时，对小岛窗口和悬浮歌词窗口调用 `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE /* 0x11 */)`；关闭时恢复 `WDA_NONE`。
- 调用失败就视为系统不支持。

### 2. 截取
- 每帧截取**窗口本身覆盖的整块屏幕区域**（固定画布的范围，物理像素，按 DPI 换算，支持多屏），这样变形动画期间截取区域不变。
- 用 GDI `BitBlt` 从屏幕 DC 截图即可，被排除的窗口不会出现在结果里。截图后缩小到 50%，写进一个复用的 `WriteableBitmap`，不要每帧新建对象。
- **帧率**：展开时约 15fps，收起 / Compact 时约 8fps；窗口隐藏时停止；“减少动态效果”打开时降到 4fps。
- 截图出现异常时，自动关闭背景模糊，收起态文字提示“背景模糊暂时不可用”。

### 3. 显示
- 在投影板和颗粒层之间加一层 `Image`，显示截下来的画面，按窗口位置对齐（画面里岛的位置要和岛完全重合）。
- 加 `BlurEffect`，半径约为 `clamp(0.07h, 3, 16) × 1.8`，h 是岛当前的高度，跟随变形变化。这个 Effect 只加在这一层上，不包住任何文字。
- 开启时，tint 的不透明度 × 0.6（方案页“真实模糊”模式是 × 0.55），用户的“浓度”滑块照样生效。外投影保留。
- 悬浮歌词用同一套逻辑。请抽成一个共用的 `BackdropCapture` 辅助类。

### 4. 性能检查
- 在报告里写上开启前后的 CPU 占用：静止桌面、浏览器滚动、播放视频三种情况各一个数字。

## 截图与验收
- **注意**：开启后系统截图截不到小岛。截效果图时请先用一个关掉隐身的调试开关（只在 Debug 构建里有），或者用 `RenderTargetBitmap` 离屏渲染。
- 截图：浅色壁纸、深色壁纸、浏览器文字页面三种背景下，开启背景模糊的展开态和收起态，与 `docs/v0.7/design/ref/preset-*` 对比。

## 补充（用户追加）：设置窗口也要跟随模糊
- 背景模糊开启时，**完整设置窗口**和小岛、悬浮歌词一样，用同一个 `BackdropCapture` 做磨砂背景，同时对它调用 `WDA_EXCLUDEFROMCAPTURE`。
- 设置窗口是一大块圆角矩形（760×520，圆角 `Radius.XL`），模糊半径可以取上限 16 × 1.8；帧率和小岛展开态一样，约 15fps。设置窗口最小化或关闭时停止截取。
- 头像裁剪窗口、各个下拉弹层和菜单**不需要**模糊，保持现在至少 90% 不透明的底色，保证文字清楚。
- 在设置窗口里切换「背景模糊」开关时，设置窗口自己也要立刻生效。
- 截图：开启背景模糊后的设置窗口（「外观」页），放在浅色壁纸和文字页面两种背景上。
