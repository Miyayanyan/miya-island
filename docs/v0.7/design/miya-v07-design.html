Design Tokens

一套 token，三个窗口共用

主岛、悬浮歌词和弹层都从同一个 Themes/Tokens.xaml 取值。preset 切换只换颜色 token，尺寸、圆角、间距和动画不变。尺寸从 Thor 的 dp 体系按桌面密度缩小。

  • Display Segoe UI Variable Display, Segoe UI, Microsoft YaHei UI

渲染与动画稳定性

  • TextFormattingMode=Ideal：Display 模式会把字形对齐到像素，动画中途会跳。
  • TextRenderingMode=Grayscale：透明窗口本来就用不了 ClearType，明确设成灰度，避免不同机器效果不一。
  • TextHintingMode=Animated：只加在会动的内容层上。
  • UseLayoutRounding=True 加在三个窗口上；数字用 Typography.NumeralAlignment="Tabular"。
  • 文字永远不放进 ScaleTransform，也不放在带 Effect 的元素里面（见动画章节）。

Liquid Glass

从 Figma 到 Thor 到 WPF

Thor 和 Miya Island 用的是同一份配方：JoyTaung 文件里每块玻璃都是“背景模糊 → 液化边 → 边缘散射 → 高光”四层。Thor 在 Android 上能拿到自己的壁纸做真实折射；Miya Island 是 WPF 透明窗口，拿不到桌面，所以默认用七层叠加“仿”出来，参数按 Thor 的 GlassPolicy 随高度缩放。

尺寸缩放（GlassPolicy，h = 高度 DIP）

表面h边缘带阴影系数真实模糊

边缘带 = clamp(0.2h, 6, 22)；阴影系数 = clamp(h/80, 0.6, 1.4)；模糊 = clamp(0.07h, 3, 16)。和 Thor 的公式完全一致。

性能与清晰度规则

  • 三级玻璃（沿用 GPT 方案的叫法）：Strong 外壳（小岛、悬浮歌词、弹层、设置窗口）七层全开；Medium 透镜（选中 tab、播放键、开关、头像光环）只有底色 + 内高光 + 描边；Light 控件只有底色 + 1px 描边，没有任何 Effect。
  • 不做玻璃套玻璃：岛内区域用 Well 凹槽，不再叠玻璃。
  • Effect 不包文字：BlurEffect、DropShadowEffect 只加在单独的装饰层上；WPF 的 Effect 会把子元素整体栅格化，包住文字就会发糊。
  • 缓存：静态玻璃层加 BitmapCache；展开动画期间 L3 边缘带临时关闭模糊，结束后恢复。

Preset

PresetTint透明度 · 仿玻璃透明度 · 真实模糊文字边缘光投影适合

默认用 Midnight：最接近 v0.6.1 的深色小岛，用户升级后第一眼不会觉得“换了一个软件”。

Clear Glass 就是 Figma 原值（白 10%），最通透，但仿玻璃模式下压在浅色、杂乱背景上会看不清，所以文字加 1px 投影，设置里也会提示“建议配合真实模糊使用”。

自定义 tint：颜色 + 浓度（20%~90%）。边缘光、投影、文字颜色按亮度自动归入浅色或深色一组。

真实模糊（实验开关）

  • 设置里新增“真实背景模糊”，默认关，AppearanceSettings.ExperimentalBlur，旧 appearance.json 没有这个字段时按 false 读取。
  • 用 SetWindowCompositionAttribute 开 Acrylic，失败时退到普通模糊；都失败就把开关置灰，并提示“当前系统不支持”。
  • 系统模糊作用于整个矩形窗口，所以用窗口区域裁成胶囊形；这时外投影不显示，边缘可能有轻微锯齿，靠 1.2px Rim 盖住。
  • 展开动画期间暂停模糊，结束后恢复，避免每帧重算窗口区域；底色透明度 × 0.55，让模糊透出来。

悬浮歌词共用这套系统

  • 默认“跟随灵动岛”：同一个 preset、同一个模糊开关。
  • 在歌词“更多”菜单里可以关掉跟随，单独选 preset（比如岛用 Midnight，歌词用 Clear Glass）。
  • 单行高 44、双行高 76，按 GlassPolicy 自动得到各自的边缘带和阴影系数。

图标

圆润、轻量、细线

24×24 网格，有效区域 20，描边 1.6，圆角端点和转角，内角半径至少 1.5，不用实心填充（核心图标的双色除外）。全部是 SVG 路径，可以直接转成 WPF 的 Geometry 资源。

尺寸

16px 用在任务时间标签和 tab；18px 用在图标按钮；20px 用在播放键；24px 用在设置预览。实现时用 Viewbox 缩放，描边按 1.5 × 24 / 尺寸 反算，保证任何尺寸下看起来都是 1.5px 细线。

核心图标

动画

变形，而不是改尺寸

一次展开里，容器尺寸、圆角、阴影、内容透明度由同一个进度值驱动，所以永远同步。窗口本身不再变大小。

WPF 结构

  • 固定画布：窗口大小 = 最大展开尺寸 × 缩放 + 四周 24px 阴影边距，只创建一次；透明像素会把点击穿透给下面的窗口。
  • 一个进度值：自定义依赖属性 MorphProgress（0→1），只对它做一个 DoubleAnimation；回调里同时算出宽、高、圆角、投影强度、各内容层透明度。
  • 内容不缩放：每个状态的内容按最终尺寸排好版，放在会变形的裁剪区域里，只做淡入淡出和整像素位移。
  • 位置：_horizontalCenter 继续是唯一基准，Left = 中心 − 画布宽 / 2，展开时窗口不动，PositionFix 修的偏移从结构上不会再出现。

呼吸灯是变形的“铰链”。它是唯一一个跨状态保留的元素，位置随容器平滑移动，动画参数完全沿用 v0.6.1（1.7s、透明度 .42→1、缩放 .92→1.18、Sine），状态切换时不会重新开始闪。

Compact Mode

两个方案

两种都保留呼吸灯、都是 Liquid Glass、点击后直接展开、可以拖动并记住位置。区别在于要不要显示一点信息。

A · 小圆 32 ↔ Normal

A · 小圆 Orb　32 × 32

  • 优点：占位最小（Normal 的 15%），呼吸灯成为唯一焦点，最安静。
  • 缺点：看不到任何状态（在不在放歌、有没有到期任务）。
  • 缺点：目标小，拖动和点击需要更准，命中区要扩到 40。
  • 圆 → 胶囊要同时改宽高比，过渡里有一段“拉长”。
B · 小胶囊 104 ↔ Normal

B · 小胶囊 Mini　104 × 30　推荐

  • 优点：保留一点状态，播放时显示细律动条和时间，有到期任务时显示铃铛和数量。
  • 优点：和 Normal 是同一个胶囊形状，变形只改宽高，最顺。
  • 优点：目标更大，好点也好拖。
  • 缺点：宽度是 A 的 3 倍；有信息就会多吸引一点注意。

交互（两个方案相同）

  • 进入：展开态顶栏的“缩小”按钮；设置里可选“启动时为 Compact”。
  • 展开：单击直接到展开态。Compact 下悬停不自动展开，这样才真正不打扰。
  • 拖动：按下后移动超过 4px 算拖动，否则算单击。锁定时不能拖，但仍可单击展开。
  • 位置：Compact、Normal、Expanded 共用一个顶部中心锚点，拖哪个状态都会更新同一个位置。
  • 呼吸灯：保持单色，速度和开关沿用现有设置，不做状态变色。
Floating Lyrics

新布局

上方预览里的悬浮歌词就是新布局，鼠标移上去可以看到控制按钮，“更多”里是重做的下拉菜单。

布局规格

单行h44 · R22 · 左 20 · 右侧位 96当前句 18/26 Semibold，居中
双行h76 · R24 · 上下 12当前句 20/28 + 下一句 14/20 Ink2，间距 2

对齐与状态

  • 歌词不位移：歌词区固定在“左边距 ~ 右侧位”之间居中，控制按钮出现时不挤歌词。
  • 单双行统一：两种状态用同样的左右内边距和同一条居中轴；切换时高度用 Standard 240ms 变化。
  • 超长歌词：先降一档字号，再用省略号，不做跑马灯。
  • 换句：旧句上移 6px 淡出，新句从下方进入；双行时下一句上移变成当前句。
  • 保留的行为：拖背景移动、双击切换单双行、锁定保存、位置记忆、超出屏幕时重新放置。
  • 锁定：语义不变，只锁位置。

“更多”下拉菜单

  • 字号：小 16 / 中 18 / 大 22（分段按钮）
  • 显示下一句（即双行）· 显示时钟 · 对齐：居中 / 左对齐
  • 跟随灵动岛玻璃：关闭后可单独选 preset
  • 分隔线下方：关闭悬浮歌词
头像与问候

可选头像、自定义称呼、更大的文案池

头像和问候都可以关掉。关掉头像时，小岛和前面的方案完全一样；打开后，呼吸灯变成头像上的光环或角标，颜色、开关、速度仍然用原来的设置。

头像

  • 开关：“显示头像”，默认关闭，升级后外观不变。
  • 图片来源：内置默认头像（由 v0.6.1 的 MiyaPet.png 裁出脸部，改名为 Assets/DefaultAvatar.png 保留），或用户自定义图片（PNG / JPG / BMP / GIF 首帧；系统装了 WebP 解码器时也支持 WebP）。
  • 导入：弹出圆形裁剪框，可以拖动和缩放（100%~300%）；确认后裁成 256×256 存到 %LocalAppData%\MiyaIsland\avatar.png，原图删掉也不影响。
  • 出现的位置：收起 26 · Compact A 24 · Compact B 20 · 展开顶栏 24 · 提醒卡 34 · 问候卡 40（问候卡宽 400）。悬浮歌词那里显示专辑封面，不显示头像。

头像和呼吸灯怎么融合

  • 光环（默认）：头像外圈 2px，颜色 = 指示灯颜色。时长、透明度曲线（.42 → 1）和 v0.6.1 一样；缩放幅度从 .92→1.18 降到 1.00→1.08，避免头像跟着“跳”。
  • 角标：头像右下角 9px 小圆点，就是原来的呼吸灯，动画一模一样。
  • “开启呼吸灯”关掉时，光环和角标都静止显示。
  • 呼吸灯的逻辑代码 StartBreathingAnimation() 不改，只是动画目标从圆点换成光环或角标。

自定义称呼

  • 设置里的“我的称呼”，最多 12 个字，默认留空。
  • 填了 Miya：“早上好，Miya 今天打算做点什么？”；填了 小文：“小文，很高兴今天又见到你。”
  • 留空时，带 {name} 的句子不会被选中，只用不带称呼的句子，不会出现“，很高兴见到你”这种缺字的句子。
  • 填了称呼后，展开顶栏的标题从“Miya Island”变成“晚上好，小文”。

规则

  • 什么时候出现：启动 1.5 秒后；每次启动最多一次，距离上次至少 4 小时；可以关闭。
  • 怎么选：候选 = 当前时段 + 当前任务状态 + 特殊日子（周一、周五、周末、好久没打开、第一次启动）。有逾期时优先任务类；填了称呼时，带称呼的句子权重 ×1.5。
  • 不重复：最近用过的 8 句不会再选中（RecentGreetings）。
  • 第二行：问候卡第二行永远是客观的任务摘要，例如“今天 3 件 · 下一件 21:30 给妈妈回电话”。
  • 文案文件：内置文案放在 Assets/greetings.zh-CN.json，以后改文案不用改代码。

    怎么做

    • 新建 MusicSession：把 MainWindow.RefreshMediaAsync 里的轮询、换歌、歌词匹配原样搬过去，对外发“曲目变化 / 播放状态 / 当前行 / 下一行”事件。这是本次唯一一处较大的逻辑搬迁，服务类本身不改。
    • App.xaml 去掉 StartupUri，ShutdownMode=OnExplicitShutdown，由 App 创建两个窗口和托盘图标。
    • FloatingLyricsWindow 去掉 Owner = this，生命周期不再跟主岛绑定。
    • 托盘菜单：显示灵动岛 / 显示悬浮歌词 / 设置 / 开机自启动 / 退出。

    三种组合

    • 只开 Island：v0.6.1 的默认样子。
    • 只开 Lyrics：关闭（隐藏）主岛，歌词继续，托盘图标常驻用来找回。
    • 两个一起开：主岛显示待机标题，与 v0.6.1 现有逻辑一致。
    • 新增 ShowIsland、ShowLyrics 两个设置，启动时恢复上次的组合。
    • “退出”才真正结束程序；关闭任一窗口只是隐藏。

    位置体验

    • 默认居中：保留 CenterAtTop，“重新居中”按钮保留。
    • 轻微中心吸附：只在松开鼠标时判断。水平中心离屏幕中心 16 DIP 以内、或顶部离默认位置 10 DIP 以内，就用 160ms 滑过去；拖动过程中不吸，不做强制磁吸。按住 Alt 松开可跳过吸附。
    • 自由拖动和锁定：行为不变。
    • 记住位置：新增 IslandLeft/IslandTop + 显示器名称 + DPI；启动时检查那块屏幕还在、窗口至少露出 80px，否则回到默认居中。悬浮歌词同样规则，吸附点是水平中心和默认底部位置。

    删掉 Desktop Pet

    • 删除：PetWindow.xaml(.cs)、Models/PetState.cs、Services/PetStateService.cs、Assets/MiyaPet.png、csproj 里的 Resource、PetPanel 与“♛”入口、MainWindow 里所有 _petWindow 相关代码。
    • 用户电脑上已有的 pet.json 不删，只是不再读取。

    Tasks & Reminders

    第一版功能

    • 添加任务：输入框 + 回车；可选提醒时间。
    • 勾选完成：圆形勾选；已完成的任务折叠到“已完成”，可一键清除。
    • 一次性提醒、每日重复、指定星期重复：时间弹层里选“不重复 / 每天 / 每周”，每周可多选 一 ~ 日。
    • 到点：小岛变形成提醒卡（预览里点“提醒到点”）：完成 / 延后（10 分钟、30 分钟、1 小时、明天同一时间）/ 忽略。
    • 忽略只跳过这一次提醒，任务仍然未完成；重复任务完成后自动算出下一次。
    • 不做日历视图。tab 从 6 个变 5 个：音乐 / 任务 / 下载 / J-Space / 设置。

    数据不能丢

    • 存到 %LocalAppData%\MiyaIsland\tasks.json，带 version。
    • 原子写入：先写临时文件，再 File.Replace 并保留 tasks.json.bak；读取失败自动用备份。
    • 迁移：第一次启动时，如果有 reminders.json 而没有 tasks.json，把旧提醒转成一次性任务，原文件改名为 reminders.v06.bak.json。
    • 错过的提醒：程序关着时到点的一次性提醒，启动后标为“已过期”并计入问候，不会一次弹一串；重复任务直接跳到下一次。

    开机自启动

    • 设置和托盘菜单里各一个开关，默认关闭。
    • 写 HKCU\Software\Microsoft\Windows\CurrentVersion\Run，值为 "…\MiyaIsland.exe" --autostart，不需要管理员权限。
    • 开关状态每次都从注册表读，不信任 json；如果程序被移动、路径变了，显示“路径已变化，点击修复”。
