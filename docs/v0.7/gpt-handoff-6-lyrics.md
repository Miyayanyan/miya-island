# 任务包 #6：提高在线歌词命中率

> **状态：已由 Claude 完成（提交 db438fc），GPT 不用再做。** CI 实测 20/20 首命中，结果见 Actions 的 Lyric probe 步骤。

> 分支：从 `claude/serene-lamport-3dd2qr` 最新提交拉出 `gpt/v0.7-lyrics`，做完后交给 Claude 审查和合并。
> 只改歌词获取，不改 UI 视觉、玻璃和呼吸灯。

## 背景
用户反馈：“歌词 lrc 有点少，好多歌都没有。”用户主要用 Spotify 听中文歌，也听日文、韩文和英文歌。

目前 `Services/LyricService.cs` 只做一件事：本地缓存 → 用 `track_name + artist_name` 调一次 lrclib `/api/search` → 只取带 `syncedLyrics` 的结果。没命中就显示“暂未找到同步歌词”。常见的漏掉原因：
- Spotify 的歌名带后缀，例如 `xxx - Remastered 2011`、`xxx (feat. Y)`、`xxx（Live）`、`xxx - 电视剧《…》插曲`；
- 艺人字段里有多个人（`周杰伦, 费玉清`），或者是另一种语言的名字（`Jay Chou` 对应 `周杰伦`）；
- lrclib 收录的中文歌本来就少。

## 要求

### 1. 查询词清洗（纯逻辑，放进 Core 测试）
新建 `Services/LyricQuery.cs`，不依赖 WPF 和网络：
- 歌名清洗：去掉 ` - Remastered…`、` - Live…`、`(feat. …)`、`(with …)`、全角和半角括号里的版本说明（Live、伴奏、Remix、版、Ver. 等），以及首尾的空白和标点。
- 艺人拆分：按 `,` `、` `&` `/` `feat.` `ft.` `x` `×` 拆开，主艺人放第一个。
- 生成**按顺序尝试**的查询列表，并去掉重复项：原名 + 全部艺人 → 清洗后的名字 + 主艺人 → 只用清洗后的名字。

### 2. 歌词源链路（命中一个就停）
1. 本地缓存（保持现有格式；导入的 LRC 永远优先）。
2. lrclib `/api/get`，带上 `track_name / artist_name / album_name / duration`，用于精确匹配。
3. lrclib `/api/search`，按第 1 步的查询列表依次查；最后再用 `q=` 自由搜索一次。
4. **网易云音乐**作为中文歌的后备源，先搜索，再取歌词：
   - 搜索：`https://music.163.com/api/search/get/web?s=…&type=1&limit=10`，返回 `result.songs[]`，含 `id`、`name`、`artists[].name`、`duration`（毫秒）；
   - 歌词：`https://music.163.com/api/song/lyric?id=…&lv=1`，取 `lrc.lyric`；
   - 请求加 `Referer: https://music.163.com/` 和常见浏览器 UA；单次超时 8 秒；
   - 这是**非官方接口**，可能随时变化。失败时静默跳过，不能弹错误，也不能让整个链路报错；
   - 在报告里写清楚：这是非官方接口，个人使用可以，以后可能会失效。
5. 都没有命中，才显示现在的“暂未找到同步歌词”。

### 3. 防止配错歌词（比“少”更糟）
统一用一个打分函数筛选候选（纯逻辑，可测试）：
- 时长：知道时长时，差值 ≤ 3 秒加分最高；差值 > 15 秒的直接排除。
- 歌名：清洗、规范化后（统一大小写和全/半角，简繁不转换）相等最好，包含关系次之。
- 艺人：只要有一个艺人重合就加分。如果时长和歌名都对得上，艺人语言不同也可以接受，例如 `Jay Chou` 和 `周杰伦`。
- 必须有时间轴歌词才算命中。只有纯文本歌词的不算，这次不显示它。

### 4. 不要频繁请求
- 没命中的歌在本地记录 24 小时，期间不再联网查（负缓存，按 track key 存）；
- 一首歌的完整链路最多发约 8 个请求，按顺序发，不要并发轰炸；
- 切歌时取消上一首还没完成的查询（现在已经传了 `CancellationToken`，要一路传到底）。
- 如果界面上还没有“重新查找歌词”的入口，就在音乐页“导入 LRC”旁边的菜单里加一个，点击后清掉这首歌的负缓存再查一次。如果已经有，就复用。

### 5. 测试和报告
- Core 测试覆盖：标题清洗、艺人拆分、查询列表顺序、打分，以及时长差 > 15 秒时被排除。网络返回用 `tests/` 下的 JSON 样本，**CI 不联网**。
- 在你的 Windows 机器上，用约 30 首真实歌曲做命中率对比：中文、日文、韩文、英文都要有，也要包括带 feat. / Remastered / Live 的歌。表格列出改前、改后命中的来源，以及有没有配错。
- 用户会提供一些找不到歌词的歌名，也放进这 30 首里。
- 报告写在 `docs/v0.7/reports/6.md`。

## 不做
- 翻译歌词、逐字歌词（卡拉 OK 效果）、QQ 音乐 / 酷狗等其他源；
- 改动歌词显示的样式。
