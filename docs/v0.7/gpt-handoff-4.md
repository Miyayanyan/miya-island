## A. 用户反馈修正（先做，做完立刻推送）

### A1. 开关改成圆角矩形
- `Themes/Controls/Toggle.xaml`：
  - 轨道 36×20，圆角 **6**；
  - 拇指 16×16 的圆角方块，圆角 **4**；
  - 颜色、回弹动画、禁用状态都不变。
- 检查其他控件里还有没有胶囊或椭圆：滑块拇指可以保持圆形；滚动条拇指改为圆角 3；任务勾选框保持圆形（这是任务列表的识别符号，用户没有要求改）。

### A2. 「收起样式」：选了就自动生效

用户期望：在设置里选了小胶囊或小圆，小岛**平时收起后就是这个样子**，鼠标一离开自动变过去，而不是只有按「—」才出现。

- 新设置 `AppearanceSettings.RestStyle`：`"Normal"`（普通条，默认）/ `"Pill"`（小胶囊）/ `"Orb"`（小圆）。
- **设置页**：把原来的“Compact 样式”下拉改成“**收起样式：普通条 / 小胶囊 / 小圆**”。
  - 选择后**立即生效**：如果当前是收起状态，马上变形过去；如果当前是展开状态，下次收起时生效。
  - 删除“启动时为 Compact”开关，启动时直接用收起样式。
- **所有“收起”都回到收起样式**：鼠标离开后的自动收起、提醒卡处理完、截图前收起、顶栏的「—」按钮，全部回到 `RestStyle`。「—」的意思就是“立即收起”。
- **展开方式不变**：普通条悬停展开；小胶囊、小圆悬停不展开、单击展开；拖动规则不变。
- **旧设置迁移**：`StartCompact == true` 时，`RestStyle = CompactStyle`（Pill 或 Orb）；否则用 `Normal`。迁移后旧字段可以保留但不再使用。
- 加单元测试覆盖这个迁移规则。

## C. v0.7.1 新功能

设计依据是 Claude 的方案页。下面是需要的全部数值。每项一个提交。

### C1. 独立设置窗口
- 新建 `SettingsWindow.xaml(.cs)`：760×520，Strong 玻璃外壳（照抄主岛的投影板和玻璃层），可拖动，记住位置，只能开一个。
- 左侧导航宽 180，右侧是分组卡片（`Brush.Well` 底，圆角 14）。页面如下：
  - **常规**：开机自启动、启动时显示（小岛 / 歌词）、自动收起、收起样式、重新居中、退出；
  - **外观**：标题字体、待机标题、文字颜色、指示灯颜色、呼吸灯开关和速度、小岛大小、真实背景模糊（实验，见 C6）；
  - **头像与问候**：见 C2、C3；
  - **悬浮歌词**：见 C5；
  - **任务**：默认提醒时间、已完成保留天数；
  - **高级**：打开数据文件夹、恢复所有默认、版本号。
- 入口：小岛设置页底部加「完整设置」按钮（`Button.Primary`）、托盘菜单「设置」、右键小岛。
- 小岛里的设置页只保留常用项：收起样式、呼吸灯、小岛大小、自动收起、完整设置、退出。
- 设置改动立即生效并自动保存。两个地方改的是同一个 `AppearanceSettings`，要互相同步。

### C2. 头像（默认关闭）
- **默认头像**：从 `Assets/MiyaPet.png` 已经删掉之前的版本里取（提交 `498143c` 里还有）。以 (395, 400) 为圆心、半径 215 裁出正方形，缩放到 256×256，存为 `Assets/DefaultAvatar.png` 并作为 Resource 打进程序。
- **`AvatarService`**：`LoadCurrent()`、`SaveCustom(bitmap, cropRect)`、`ResetToDefault()`。
  - 自定义头像裁成 256×256，存为 `%LocalAppData%\MiyaIsland\avatar.png`，先写临时文件再替换；
  - 返回的 `BitmapImage` 要 Frozen，并用 `CacheOption=OnLoad`，避免锁住文件；
  - 支持 PNG / JPG / BMP / GIF 首帧；超过 20MB 拒绝，给中文提示。
- **`AvatarCropWindow`**：模态窗口，玻璃外壳，约 360×440。
  - 240px 的圆形预览，圆外是半透明遮罩；
  - 可以拖动平移，滚轮或滑块缩放 100%~300%；
  - 平移和缩放要限制在图片范围内，圆里不能出现空白；
  - 底部「取消」（Ghost）和「确定」（Primary）。
- **设置项**：`AvatarEnabled`（默认 false）、`BreathingStyle`（`"Ring"` 光环，默认 / `"Badge"` 角标）。
- **显示规则**：
  - 头像出现在：收起 26px、小胶囊 20、小圆 24、展开顶栏 24、提醒卡 34（替换铃铛透镜）、问候卡 40；
  - **光环**：头像外 2px 的环，颜色 = 指示灯颜色；透明度 .42→1、时长都跟随呼吸灯设置；缩放幅度 1.00→1.08；
  - **角标**：头像右下角 9px 的圆点，就是原来的呼吸灯；
  - 呼吸灯关闭时，两种样式都静止显示；
  - **`StartBreathingAnimation()` 的参数和逻辑不改**，只是把动画目标从圆点换到光环或角标（可以抽一个“当前指示元素”，或者让光环绑定同一个动画）。
- 头像关闭时，小岛和现在**完全一样**。

### C3. 称呼与启动问候
- **新设置**：`Nickname`（最多 12 字，默认空）、`GreetingEnabled`（默认 true）、`GreetingSource`、`CustomGreetings`、`LastGreetingAt`、`RecentGreetings`（最近 8 句）、`LastLaunchAt`、`IsFirstRun`。
- **问候卡**：
  - 启动 1.5 秒后，小岛用 `MorphTo` 变形成问候卡，`GreetShape = (400, 72, 24)`；
  - 内容：头像（开启时）或呼吸灯 + 第一行问候（14 SemiBold）+ 第二行任务摘要（11.5 `Brush.Ink2`，等宽数字）；
  - 底部 2px 的渐变细线在 6 秒内从满到空，结束后回到收起样式；
  - 点击问候卡立即收起。
- 用 `GreetingService.TryGetStartupGreeting`；`Summary` 来自 `ReminderScheduler.GetSummary`。
- **填了称呼后**，展开顶栏的标题改为“{早上好 / 中午好 / 下午好 / 晚上好 / 夜深了}，{称呼}”。
- **设置页「头像与问候」**：
  - 显示头像开关 + 64px 预览 +「更换图片」「恢复默认」；
  - 呼吸灯样式：光环 / 角标；
  - 我的称呼；
  - 启动问候开关；
  - 文案来源：内置 + 自定义 / 只用自定义；
  - 自定义问候列表：每行带删除，最多 50 句、每句 40 字以内；有一排可以点的占位符小按钮（`{name}` `{count}` `{next}` `{nexttime}` `{weekday}`），点了插入到输入框；
  - 「试一下」按钮：调 `Pick`，在旁边显示结果。

### C4. 开机自启动
- 用已有的 `AutostartService`，设置页「常规」里一个开关，默认关闭。
- 状态每次从注册表读；如果 `IsPathStale` 为真，显示“路径已变化，点击修复”。
- 启动参数里有 `--autostart` 时，按上次的显示组合启动。

### C5. 悬浮歌词「更多」菜单和专辑封面
- 悬停控制条加一个 `Icon.More` 按钮，弹出玻璃菜单：
  - **字号**：小 16 / 中 18 / 大 22，三段式（双行时当前句 +2）；
  - **显示下一句**（就是双行）；
  - **显示时钟**；
  - **对齐**：居中 / 左对齐；
  - **显示专辑封面**；
  - 分隔线；
  - **关闭悬浮歌词**。
- **专辑封面**：在 `MediaService` 读取系统媒体的 `Thumbnail`（只在换歌时读一次），通过 `MusicState` 传出去。
  - 单行时 28px，圆角 8，在歌词左边；双行时 56px，圆角 12；
  - 没有封面时显示一个渐变占位块；
  - 歌词仍然在剩余空间里居中。
- 设置都保存，并在设置窗口的「悬浮歌词」页同步显示。

### C6. 真实背景模糊（实验，默认关）
- `ExperimentalBlur` 设置，开关放在设置窗口的「外观」页，说明写“实验功能，开启时不显示外投影”。
- 用 `SetWindowCompositionAttribute` 开 Acrylic，失败时退到普通模糊；都失败就把开关置灰，提示“当前系统不支持”。
- 开启时：
  - 用 `SetWindowRgn` 把窗口裁成岛的圆角形状，变形动画期间暂停模糊，结束后恢复；
  - 底色透明度 × 0.55；
  - 隐藏投影板的投影。
- 悬浮歌词跟随同一个开关。
